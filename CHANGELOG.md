# Changelog

What changed on [WOODWERD Toolkit Guides](https://woodwerd.github.io/), newest first. Versions are x-numbers while the site is new.

## x0.0.4 · 2026-11-06
- Set up GitHub no longer says one repo serves every tool. Tools that work together share a repo, and a tool that stands on its own gets its own. Each tool's guide says which.
- Step 4 now covers a tool with a repo of its own: a new private repo and a token for just that repo.

## x0.0.3 · 2026-11-06
- The guide's menu marks the section you're reading with an amber bar.

## x0.0.2 · 2026-11-06
- The menu on the left stays in place as you scroll, like the other WOODWERD guides. On phones it stays at the top of the page.

## x0.0.1 · 2026-11-06
- First version: a home for how-tos shared by every WOODWERD tool.
- Set up GitHub, step by step: a free account, one private repo, one token for that repo only, connecting a tool, a read-only token for review-only phones, more devices, fixes and the words used. It used to live on Box Ctrl's site and now serves every tool equally.
